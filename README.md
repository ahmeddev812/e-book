# 📚 E-Book Store

A modern, responsive, and premium eBook Store built with **Next.js 16**, **React**, **TypeScript**, and **Tailwind CSS**. The platform provides a seamless browsing experience for digital books with category-based navigation, search functionality, shopping cart, authentication, and secure checkout.

> Designed to deliver a clean, fast, and engaging reading marketplace experience.

---

## ✨ Features

- 📖 Browse books by categories
- 🔍 Search books instantly
- 📚 Dynamic Book Details Pages
- ❤️ Wishlist Support
- 🛒 Shopping Cart
- 💳 Stripe Checkout Integration
- 🔐 Clerk Authentication

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/ahmeddev812/e-book.git
```

### Navigate to Project

```bash
cd e-book
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file in the root directory.

Example:

```env
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_key
CLERK_SECRET_KEY=your_key

NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_key
STRIPE_SECRET_KEY=your_key
```

---

### Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
